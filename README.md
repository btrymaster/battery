# 배터리마스터 홈 화면 앱

ZIP 압축을 푼 뒤 index.html, manifest.webmanifest, icons 폴더를 모두 GitHub 저장소 최상위에 업로드하세요.
기존 index.html은 교체합니다. ZIP 자체를 업로드하지 마세요.
.nojekyll은 선택 사항입니다.
기존 GitHub Pages 설정(main / root)은 그대로 사용합니다.

안드로이드: Chrome에서 사이트 접속 → ⋮ 메뉴 → 홈 화면에 추가 또는 앱 설치 → 설치/추가.
아이폰: Safari에서 사이트 접속 → 공유 → 홈 화면에 추가 → 웹 앱으로 열기 옵션이 있으면 켜기 → 추가.
홈 화면의 배터리마스터 아이콘으로 실행하세요.
기존 바로가기가 있으면 삭제한 후 다시 추가하면 새 아이콘과 앱 설정을 적용할 수 있습니다.

인터넷 연결이 필요합니다. 앱스토어 등록이나 서버 설치는 필요하지 않습니다.
아이콘은 제공된 로고를 앱용 크기로 변환했습니다. 차량 데이터와 검색 기능은 동일합니다.

사이트 상단의 앱 설치 / 홈 화면에 추가 버튼으로 설치 창 또는 기기별 안내를 열 수 있습니다. 사용자 확인 없이 자동 설치되지는 않습니다.
